ON-CHAIN / MOEDAS PARADAS

Fonte atual:
- CoinMetrics Community API gratuita
- Sem chave paga
- Sem Bitbo

Endpoint externo:
https://community-api.coinmetrics.io/v4/timeseries/asset-metrics

Endpoint interno:
/api/onchain-dormant

Métricas:
- SplyCur
- SplyAct1yr
- SplyAct2yr
- SplyAct3yr
- SplyAct4yr
- SplyAct5yr
- tentativa de SplyAct7yr e SplyAct10yr se disponíveis na Community API

Cálculo:
BTC não movimentado há N anos = SplyCur - SplyActNyr
